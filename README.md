# КейсПортал

Портал мероприятий: витрина событий, регистрация команд на кейс-чемпионаты
(и простая запись на лекции), загрузка решений, оценка судьями по критериям
и таблица лидеров.

Стек: **Next.js (App Router) + Refine v5 + Supabase** (БД, авторизация, Storage).

## Возможности

- **Витрина событий** — лента опубликованных мероприятий с форматами
  «кейс-чемпионат» и «лекция», счётчиками заявок и решений.
- **Регистрация** — команда с названием и выбором кейса (для чемпионата)
  или просто запись (для лекции). Заявку одобряет организатор.
- **Решения** — команда загружает файл решения (Supabase Storage) после
  одобрения заявки.
- **Судейство** — организатор добавляет судей по e-mail; пользователь
  подтверждает приглашение в разделе «Судейство» и получает права судьи.
  Автор мероприятия — судья по умолчанию.
- **Оценки** — судьи выставляют баллы по критериям события, формируется
  общий балл работы.
- **Таблица лидеров** — публичный рейтинг команд/участников по баллам.
- **Дашборд организатора** — создание мероприятий (кейсы + критерии),
  статистика: кто записался, какие решения сдали, управление статусами
  заявок и составом жюри.

## Запуск

1. Создайте проект на [supabase.com](https://supabase.com).
2. Выполните SQL из `supabase/schema.sql` в SQL Editor проекта
   (таблицы, RLS, триггер профиля, представления, bucket `solutions`).
3. Скопируйте `.env.example` в `.env.local` и подставьте URL и anon key
   проекта (Settings → API).
4. Запустите dev-сервер:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Структура

```
app/
  page.tsx                  витрина событий (hero + лента)
  events/[id]               страница события + кейсы
  events/[id]/register      регистрация команды/участника
  leaderboard               таблица лидеров
  login, register           авторизация (Supabase Auth)
  my/                       дашборд организатора
  my/events/new             создание мероприятия (кейсы, критерии)
  my/events/[id]            статистика, заявки, решения, судьи
  my/registrations          мои заявки + загрузка решений
  judge/                    панель судьи (приглашения, очередь работ)
  judge/review/[id]         оценочный лист
lib/                        supabase-клиент, auth-провайдер refine
supabase/schema.sql         полная схема БД с RLS
```

## Роли и доступ (RLS)

- Аноним: читает опубликованные события, кейсы, лидеров.
- Пользователь: регистрируется на события, создаёт свои, видит свои заявки
  и решения, загружает решения.
- Организатор события: управляет им, заявками, кейсами, критериями,
  назначает судей.
- Судья (автор — по умолчанию): видит решения своих событий, ставит оценки.
